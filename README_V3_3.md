# صيدلية عبدالهادي — v3.3 FINAL FIX

هذه النسخة تصلح مشاكل لوحة الإدارة التي ظهرت في v3.2:

- زر تحديث فعلي مع حالة تحميل واضحة في المنتجات والمخزون والطلبات والوصفات والموردين والعملاء والأمان ولوحة التحكم.
- معالجة أخطاء القراءة بدل تجاهلها بصمت.
- تحديث المخزون والمنتجات معًا عند Refresh.
- إصلاح عرض سعر البيع في المنتجات.
- إضافة/حفظ الدفعات والمخزون.
- إصلاح رفع الوصفات: التحقق من الجلسة والدور، النوع والحجم، رفع Storage الخاص ثم تسجيل الملف في جدول prescriptions، وحذف الملف من Storage إذا فشل تسجيل قاعدة البيانات.
- إنشاء رابط مؤقت Signed URL لعرض الوصفة.
- صلاحيات RLS إدارية متسقة للمنتجات والدفعات والطلبات والوصفات والموردين والعملاء والمشتريات والمبيعات.
- التأكد من أن bucket `prescriptions` خاص وغير عام، بحد 10MB والأنواع المحددة.

## التشغيل
1. استبدل ملفات مشروع GitHub بمحتويات هذا المجلد.
2. اترك `.env.local` خارج GitHub.
3. شغّل `FINAL_FIX.sql` مرة واحدة في Supabase SQL Editor.
4. انتظر Deployment Vercel.
5. سجّل الدخول كمدير ثم اختبر Refresh في كل قائمة ورفع وصفة.
