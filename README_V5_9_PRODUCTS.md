# Pharmacy Abdelhadi v5.9 — Pharmacy Products

## التعديلات
- قارئ باركود USB تلقائي عند إضافة المنتج وعند البحث، بدون زر.
- ماسح كاميرا في البحث.
- اقتراح المادة الفعالة بعد حرفين من المواد المحفوظة.
- إزالة التصنيف من نموذج إضافة المنتج.
- منع الأسعار السالبة في الواجهة وقاعدة البيانات.
- حد إعادة الطلب الافتراضي للمنتجات الجديدة = 1.
- جدول المنتجات: حذف عمود الوحدة/الأجزاء، وإضافة الشركة بعد الاسم العلمي.
- اسم الدواء يظهر مع العيار.
- إصلاح حفظ تعديل المنتج عبر RPC إداري.
- إصلاح حذف المنتج: حذف فعلي عند عدم وجود سجلات مرتبطة، وأرشفة آمنة عند وجود تاريخ مرتبط.
- الحفاظ على طريقة البحث الحالية.
