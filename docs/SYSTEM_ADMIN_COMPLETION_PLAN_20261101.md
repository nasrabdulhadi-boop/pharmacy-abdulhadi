# خطة إغلاق مركز إدارة النظام

النطاق: الفرع التجريبي وSupabase QA فقط. لا تغيير للإنتاج، لا خدمة مدفوعة، لا تعديل لبيانات أو حسابات الصيدلية الأصلية. الإنجاز يتطلب نتيجة اختبار مسجلة؛ الاختبار المتجاوز أو نجاح البناء وحده لا يكفي.

| المرحلة | التنفيذ | شرط الإغلاق |
| --- | --- | --- |
| 1. تثبيت النطاق | تسجيل نسخة المصدر، جرد وظائف المركز، فصل إعدادات QA والإنتاج | لا كتابة إلى مشروع الإنتاج ولا مفاتيح خادم في المتصفح |
| 2. الحسابات والصلاحيات | دخول مالك ومدير وموظف ودعم وحساب بلا دور؛ فحص REST/RPC/RLS والتجاوزات | قبول العمليات المسموحة ورفض جميع المسارات الحساسة، بما فيها طلب مباشر خارج الواجهة |
| 3. الجلسات | تخفيض الدور أثناء بقاء JWT، خروج شامل، انتهاء الجلسة | رفض الصلاحية القديمة من قاعدة البيانات فوراً؛ لا اعتماد على إخفاء الأزرار |
| 4. كلمات المرور والاسترداد | حساب مؤقت فقط: تحقق OTP، رفض خاطئ ومنتهي ومستخدم، تغيير كلمة المرور، دخول جديد | نتيجة Auth حقيقية؛ البريد والتسليم مرحلة مستقلة لا يعوضها إعداد رمز اصطناعي |
| 5. مركز الإدارة | الملف الشخصي، اللغة والمظهر، عرض الصلاحيات، صحة الخدمات | وظائف متصلة فعلياً مع حالات تحميل وفشل وبيانات منقحة للدعم |
| 6. النسخ الاحتياطي | نسخة متسقة مشفرة وصلاحيات وصول وتوثيق النطاق والتحقق من التجزئة | ملف حقيقي محفوظ، ثم استعادة معزولة تشمل البنية والدوال والسياسات والعلاقات والأرصدة |
| 7. توافق الصيدلية | البيع والأجزاء والمشتريات والبونص والجرد والصندوق والعملات والموردون والمتدينون والتدقيق | اختبارات قاعدة بيانات + HTTP + متصفح، مع بيانات اصطناعية فقط |
| 8. تجهيز التسليم | تقرير الأدلة، الموانع، خطة تراجع وترحيل إضافي قابل للمراجعة | لا بنود مخفية أو نجاح مفترض؛ النقل للإنتاج يحتاج موافقة منفصلة |

## ترتيب التنفيذ

ابدأ باختبارات HTTP بحسابات QA مؤقتة، ثم اختبارات المتصفح وتغيير الجلسات، ثم الاسترداد. راجع الدوال المنشورة لاكتشاف مسارات خارج صلاحيات المركز. بالتوازي المنطقي افحص إمكانية تشغيل PostgreSQL محلياً وتجهيز النسخ دون إنشاء بنية مدفوعة. أي نقص في وصول البريد أو اتصال قاعدة البيانات يوثّق بعينه، وتستمر البنود المستقلة عنه.

لا يُعطى ضمان «صفر أخطاء» أو نسبة إنجاز مضللة. الحالة النهائية تكون: منفذ ومختبر، منفذ وينتظر تحققاً، أو غير منفذ؛ وتذكر قيود كل دليل.
