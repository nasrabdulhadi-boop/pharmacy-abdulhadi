# متابعة المساعد السريري — 2026-10-26

الفرع: `feature/clinical-assistant-preview-v1`. هذه متابعة بعد تقرير الاختبار الفعلي، وليست إغلاقاً لجميع متطلبات الإطلاق.

## ما تغيّر

- استخراج تحميل تدقيق المنتجات إلى `src/clinicalAuditLoader.js` واستخدامه في صفحة المساعد وحدها.
- طلب حقول المراجعة الثمانية فقط عبر projection على RPC القائم: id، name، barcode، active_ingredient، strength، dosage_form، manufacturer، active. لا تُطلب الأسعار ضمن التدقيق الجديد، وتُحذف الحقول الإضافية دفاعياً من نتيجة المحمّل.
- رفض الصفوف ذات المعرّفات المفقودة أو المكررة ضمن الصفحة أو بين الصفحات، والأشكال غير الصالحة، والصفحات الأكبر من المطلوب، والصفوف غير النشطة أو ذات أنواع حقول غير متوقعة.
- لا تعني الصفحة القصيرة اكتمال التدقيق؛ يتابع المحمّل من العدد المسترجع فعلاً حتى صفحة فارغة أو بلوغ حد المراجعة. هذا يمنع اقتطاع التدقيق إذا خفّضت الخدمة حجم الصفحات.
- مراجعة 20 ألف منتج كحد أقصى مع طلب تحقق إضافي من سجل واحد لتمييز العدد المطابق للحد عن الاقتطاع.
- مهلة 30 ثانية لكل صفحة، وإلغاء الطلب الجاري عبر AbortSignal عند انتهاء المهلة أو مغادرة الصفحة أو الإيقاف.
- إضافة زر «إيقاف التدقيق». الإيقاف أو فشل التحميل لا يعتمد النتائج الجزئية ولا يتيح تصديرها.
- رسائل أخطاء عربية وإعلان الخطأ عبر role=alert دون كشف رسالة خادم قاعدة البيانات الداخلية.

لا يتغير بحث نقطة البيع أو المشتريات أو المخزون أو المحاسبة أو واجهة العملاء. قورنت نسخة main.jsx مع الأساس آلياً بعد استبعاد دالة ClinicalPreview واستيراد المحمّل؛ بقية الملف مطابقة.

## التحقق المنفّذ

- `npm run build`: **156 اختباراً ناجحاً، صفر فشل، صفر تخطٍّ**، ونجاح Vite. تحذير الحزمة الأكبر من 500 kB ما زال قائماً.
- 13 حالة جديدة تختبر: صفحات متتابعة، استبعاد الأسعار، حد السجلات، الصفحات القصيرة، التكرار، أنواع البيانات، فشل الصفحة التالية، سلامة سجل التحقق الإضافي، المهلة، إلغاء طلب لا يستجيب، الإلغاء المسبق، الإعدادات غير الصالحة، كتالوج اصطناعي من 20 ألف سجل، وتكامل SDK الحقيقي مع ناقل اختبار معزول.
- دمج عدة assertions في الحالة الواحدة لا يعني زيادة عدّاد الاختبارات؛ المجموع الجديد 156 بدلاً من 143.
- اختبار HTTP قراءة فقط على RPC القائم بالحقول المحددة: HTTP 200 مع صفر صفوف للزائر. يثبت قبول projection وحجب بيانات RPC عن الزائر؛ **لا يثبت تجربة المدير أو زر الإيقاف في المتصفح بعد هذا التعديل**.
- مجموعة SQL المعزولة بقيت 23 اختباراً من الجولة السابقة؛ لم يتغير مقترح SQL أو صلاحياته في هذه المتابعة ولم يُعَد تشغيلها بلا سبب.
- لا يضمن هذا التحميل لقطة زمنية ثابتة إذا غيّر مستخدم آخر ترتيب المنتجات أثناء قراءة الصفحات؛ اكتشاف التكرار لا يستطيع إثبات غياب كل حذف/إضافة متزامنة.

## تعثّر بيئة Supabase المنفصلة

أُعيدت محاولة إنشاء فرع `clinical-assistant-security-qa` على مشروع الصيدلية عبر الموصل. أعاد الطلب `Invalid or expired requestState` مرة أخرى. أُعيد فحص قائمة الفروع وكانت فارغة. توقفت المحاولات المتكررة بعد تكرر الخطأ. لم يُنشأ فرع ناجح ولم يُطبّق SQL على الصيدلية.

لا توجد بيئة PostgreSQL/Supabase محلية كاملة متاحة في هذه الحاوية؛ اختبارات PGlite ليست بديلاً عن Auth وPostgREST الحقيقيين. لم يُشترَ اشتراك أو تُؤكَّد تكلفة لإنشاء مورد جديد.
