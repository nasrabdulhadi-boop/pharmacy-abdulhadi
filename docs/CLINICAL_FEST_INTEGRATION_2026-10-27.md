## ما أُضيف

مرجع فعلي قابل للبحث، مستقل عن مطابقة منتجات الصيدلية. مصدره الملف البشري العام Rekvirent 2.5.1 من هيئة المنتجات الطبية النرويجية DMP، وليس ملف Farmalogg/NAV المقيد. يُختار من مادتين إلى ثماني هويات صريحة من المصدر، بالاسم النرويجي أو الاسم الإنكليزي المتاح أو رمز ATC. لا توجد مطابقة تلقائية للأسماء التجارية أو الأملاح أو أسماء المنتجات العربية.

- 11,050 سجل تداخل؛ 4,530 «ينبغي تجنبه»، 5,917 «تؤخذ احتياطات»، 603 «لا إجراء وفق سياق المصدر».
- 456 سجل «لم يُقيّم»؛ لا يتحول أي منها إلى تصريح بالأمان.
- 4,297 هوية مفهرسة؛ تسلسل ATC يُطبق على مستويات صحيحة فقط، والاختيار لهويات المصدر المفردة المتاحة.
- النصوص الأصلية محفوظة: 1,322 شرط انطباق و20,623 إحالة مرجعية، مع الآلية والعاقبة والتعامل وأساس الدليل.
- بعض الحقول/الإحالات غير موجودة لدى المصدر نفسه؛ تُعرض صراحة ولا نختلقها.
- ملفات مضغوطة مجزأة، تحميل عند الطلب، وبصمة SHA-256 لكل ملف تمنع اختلاط الإصدارات أو اعتماد تحميل جزئي.
- لا تُرسل اختيارات المواد أو أي بيانات للصيدلية إلى DMP. الاتصال الخارجي يطلب ملفاً عاماً ثابت العنوان فقط.
- التحقق من الحداثة يقارن بصمة ZIP الرسمي كاملاً؛ يوقف النتائج عند تغيره أو تعذر الاتصال. التحقق صالح لخمس دقائق، ويعاد عند كل فحص؛ ذاكرة الخادم تخفف التنزيلات لمدة أربع دقائق فقط.

## التحقق

- 179 اختبار JavaScript ناجح، منها 14 اختباراً لهذا الدمج. تشمل سلامة جميع الملفات، اكتمال السجلات، حدود الاختيار، ترتيب الأزواج، ATC، الحالات غير المقيّمة، غياب السجلات، فشل الملفات، الروابط غير الآمنة وانتهاء الصلاحية وتغير المصدر وتعطل الاتصال.
- 6 اختبارات Python ناجحة للمستورد: سياق المصدر، الحقول الجديدة، الحالة غير النشطة، عدد المجموعات، التصنيف المجهول ورفض الملفات غير المخصصة لهذا الاستخراج.
- ثلاثة أزواج فعلية أرجعت سجلات المصدر وتصنيف «ينبغي تجنبه»: clopidogrel/omeprazole، simvastatin/clarithromycin، sildenafil/glyceryl trinitrate. هذا تحقق من النقل والمطابقة، وليس اعتماداً سريرياً مستقلاً.
- `npm run build` ناجح. يستمر تحذير Vite السابق عن حجم الحزمة الرئيسية؛ البيانات السريرية ليست داخل الحزمة وتُحمّل مضغوطة عند الطلب.
- تحقق مباشر من المصدر الرسمي نجح محلياً ببصمة مطابقة يوم 27 أكتوبر 2026.

## الحدود والعمل المتبقي للاستخدام السريري الكامل

هذا يُكمل إضافة المصدر المرجعي، ولا يُكمل تلقائياً اعتماد تنبيهات منتجات الصيدلية. يلزم اعتماد مطابقة هويات المنتجات، ومراجعة صيدلانية لاختبارات حالات واقعية وشروط الطريق والجرعة، وترجمة طبية مراجعة إذا أُريد عرض النصوص العلاجية بالعربية. لا يجوز تحويل نتائج عدم العثور إلى «لا تداخل» أو «آمن». بعض المواد لها أكثر من رمز، ولا يُستنتج تكافؤ رموزها تلقائياً.

القيود الأمنية المكتشفة سابقاً في قاعدة الإنتاج ما زالت خارج هذا التغيير؛ نجاح اختبارات RLS في مشروع QA المعزول لا يعني إصلاح الإنتاج. لم نغيّر سياساته.

## إعادة الاستيراد الكامل

نزّل ZIP العام المشار إليه في `src/festManifest.json` عبر GET، واحفظه خارج المستودع. ثم:

```sh
python scripts/import_fest.py /path/to/fest251.zip --last-modified 'HTTP Last-Modified date'
python -m unittest discover -s tests -p 'test_fest_import.py'
npm run build
```

يفحص المستورد الملف كاملاً قبل استبدال الملفات المحلية؛ يحتفظ بالنصوص والشروط، ويرفض تغييرات المخطط غير المعروفة. يلزم مراجعة تغير الأعداد والحالات المرجعية وتحديث اختبارات الإصدار عند تغير المصدر، ثم نشر الفرع التجريبي. لا تكتب أداة الاستيراد إلى Supabase. عند وجود نسخة أحدث، تتوقف الواجهة إلى أن يكتمل هذا التحديث وتنجح الاختبارات؛ لا يوجد تحديث صامت للبيانات الطبية.
