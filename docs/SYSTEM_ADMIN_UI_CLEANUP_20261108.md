# اختصار مركز الإدارة — 8 نوفمبر 2026

بناءً على طلب المستخدم، أُزيل جدول مصفوفة الصلاحيات التوضيحي، وسجل تقدم التطوير وبطاقاته، والترويسة الدعائية، والشروحات واللوحات المكررة، ومعرّف المستخدم التقني، وفاحص وصف النسخة التجريبي القديم. يبقى سجل تقدم التطوير في الشيفرة والتقارير ولا يعرض داخل واجهة التشغيل.

أُبقي جدول الحسابات التشغيلي وأزرار تغيير الدور والدعوة، وأدوات الملف الشخصي وكلمة المرور والجلسات والاسترداد، والتصدير المشفر وفحص سلامة الملف، وإعدادات اللغة والكثافة. اختُصرت التعليمات إلى ما يحتاجه المستخدم لاتخاذ الإجراء؛ بقي تحذير سرية رابط الدعوة، وأهمية عبارة التشفير، وعدم توفر الاستعادة الكاملة. لا توجد تغييرات في صلاحيات الخادم أو Auth أو قاعدة البيانات.

قُلّلت ارتفاعات بطاقات الحالة وأزرار الاختصارات والفراغات الداخلية. التعديلات محصورة بمركز الإدارة على QA، دون نشر main أو تعديل الإنتاج. لم تُعد اختبارات Auth الحية باستخدام الحسابات الأصلية؛ التغيير عرضي، وحسابات الاختبار السابقة محذوفة.

التحقق: 137 اختباراً محلياً ناجحاً، صفر فشل، واختبار دعم حي واحد متخطى لعدم وجود حساب مؤقت؛ 63 فحص SSR ناجحاً؛ بناء staging وproduction mode المحلي ناجحان. حُدثت اختبارات التصميم القديمة التي كانت تشترط العناصر التي طلب المستخدم إزالتها، وأُزيل اختبار عرض سجل التقدم الذي لم يعد جزءاً من الواجهة.

المتصفح: فُحصت التبويبات الخمسة بمكوّن محلي ببيانات محاكاة، والعربية والإنجليزية، والعرض الضيق والمظهر الداكن. بقي جدول حسابات واحد فقط في قسم الأدوار، وبقي فاحص النسخة المشفرة الفعلي؛ لا يُدّعى اختبار تسجيل دخول متصفح حي بهذه الجولة. مصدر بيانات المحاكاة غير منشور.
