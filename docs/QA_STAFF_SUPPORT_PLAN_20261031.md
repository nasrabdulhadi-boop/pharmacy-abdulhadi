## التنفيذ بهذه الدفعة

- إضافة لوحة قابلة للفتح «متابعة طلباتي — قرارات المدير» داخل Admin الأصلي للموظف فقط وفي QA فقط. تعرض آخر 20 طلباً، العملية والحالة والتاريخ ورقم مختصر؛ لا تعرض payload أو معرفات الموظفين/المديرين أو أرقاماً مالية.
- لا تجلب اللوحة البيانات قبل فتحها. التحديث يدوي، وتُرفض نتائج التحميل القديمة بعد الإغلاق أو التفكيك. فشل التحميل يمسح القائمة ويعرض خطأ بدلاً من بيانات قديمة.
- استخدام `qa_sandbox_requests` الحالية: الخادم يعيد طلبات صاحب الجلسة فقط للموظف، ويمنع الدعم. لم تُضف صلاحيات أو دوال قاعدة بيانات جديدة.
- إضافة اختبارات التحويل الآمن للبيانات، واختبار تكامل للواجهة عبر HTTP للتحقق من الإرسال ومتابعة الرفض وعدم تغير المخزون ومنع الدعم.
- تجهيز أربعة حسابات Auth اصطناعية جديدة بأدوار مستقلة عبر Auth Admin API. كلمة المرور عشوائية ومحفوظة مؤقتاً خارج المستودع. فشلت المحاولة الأولى قبل إنشاء أي حساب؛ نجحت الثانية. أُعيد تعطيل نقطة التجهيز فوراً مع تفعيل JWT.
