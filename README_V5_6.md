# Pharmacy Abdelhadi v5.6

## New systems
- Barcode camera + USB scanner intake inside purchase invoices.
- Cash / credit sale flow in POS.
- Debtor files, ledger, payments and payment timestamps.
- Cashbox with daily/date-range movements and manual expense/income/withdrawal/deposit.
- Integrated accounting reports: sales, purchases, cash/credit sales, debt, collections, gross profit, margin, cashbox and date-range comparison.
- Smart inventory: search a single product by name/barcode and count only that product, while retaining full-count mode.

## Deployment
1. Deploy the project files.
2. Run `V5_6_ACCOUNTING.sql` once in Supabase SQL Editor.
3. Test barcode intake, cash sale, credit sale, debtor payment, cashbox and a custom report period.
