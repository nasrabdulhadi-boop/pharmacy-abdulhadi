# Pharmacy Abdelhadi v5.5

Release includes:
- One-source quantity editing: inventory only; material card is display/traceability only.
- Smart inventory center: stock alerts, reorder recommendations, expiry monitoring, disposal workflow, full inventory count and variance approval.
- Profit dashboard and existing profit reports.
- FEFO sale logic retained.
- Customer and supplier returns with stock movements and audit logs.
- Customer profiles with order history and spending summary.
- Expanded audit trail for inventory counts, disposal, returns and product price changes, plus existing purchase add/delete audit.
- PWA manifest/service worker for installable mobile experience.

Run `V5_5_UPGRADE.sql` once in Supabase, then deploy the project to GitHub/Vercel.
