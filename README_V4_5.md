# Pharmacy Abdelhadi v4.5 — المشتريات والموردون والتتبع

## الفكرة
تم ربط دورة الشراء كاملة:

**المورد → فاتورة شراء → أصناف الفاتورة → دفعات المخزون → حركة شراء**

وبالتالي تستطيع معرفة مصدر أي دفعة: من أي مورد، ومن أي فاتورة، وبأي سعر شراء، ومتى استلمت.

## ما الجديد
- صفحة **المشتريات** لإنشاء فاتورة شراء متعددة الأصناف.
- اختيار المورد، رقم الفاتورة، التاريخ والملاحظات.
- لكل صنف: المنتج، الكمية، سعر الشراء، سعر المبيع، تاريخ الانتهاء.
- عند حفظ الفاتورة يتم تلقائياً:
  - إنشاء فاتورة شراء.
  - إنشاء دفعة مخزون لكل صنف.
  - إضافة الكمية للمخزون.
  - تسجيل حركة `purchase`.
  - ربط الدفعة بالمورد والفاتورة.
  - تحديث سعر الشراء/المبيع الافتراضي للمنتج.
  - تسجيل العملية في audit log.
- بطاقات المواد والمخزون تعرض المورد ورقم الفاتورة لكل دفعة.
- صفحة الموردين تعرض سجل مشتريات المورد.

## مهم
النسخة لا تغيّر آلية البيع FEFO الحالية ولا تخفي المنتجات أو الدفعات القديمة. الحقول القديمة مثل `batch_number` تبقى في قاعدة البيانات للتوافق، لكن رقم التشغيلة لا يظهر كحقل مطلوب في واجهة الاستلام.
